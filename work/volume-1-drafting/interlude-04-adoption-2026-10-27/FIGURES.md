# Original grayscale figures

`build_figures.py` uses only Python's standard library and writes two SVGs into a local `figures/` directory. Run it from a temporary copy of this record directory to avoid creating unused assets in the repository, then compare generated SVG bytes with `manuscripts/volume-1/assets/04-interlude/`. PNGs in `figure-previews/` were rendered from the final SVGs with Sharp and visually inspected.

The semaphore figure illustrates an extra wait that prevents progress; it is not a recovered course assignment. The training/serving figure abstracts ordinary fixed-weight serving and gradient-based training; it does not enumerate every layer, cache or autoregressive decoding step. Both have process captions in the manuscript. The final print size and pagination remain edition-specific publishing work.
